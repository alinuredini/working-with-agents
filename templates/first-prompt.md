# First prompt

```text
We're planning, not building yet.

1. Read AGENTS.md, DESIGN.md and STACK.md in this folder.
2. Using STACK.md, propose 2–3 stacks with cost, upkeep and lock-in, recommend one,
   and wait for my pick.
3. After I pick: build ONE static HTML mock of the first screen — use the tokens
   in DESIGN.md, fictional people and companies, and a light/dark toggle.
   No app code yet.
4. Wait for my reaction to the mock before writing any app code.

If anything in these files is unclear or looks wrong, say so before you start.
```
